## 三、主线叙事：我发现了什么

**故事线**：我从"预测 IL 性质"开始（论文 1-6），发现数据密度是关键（CCS）。然后我问了一个更深的问题：**模型的架构（等变 vs 标量）到底值多少钱？**——这引出了我的核心科学问题：

> **等变性的价值，能否被数据、容量、复杂性定量"替代"？**

我通过 4000+ 次消融实验（8 IL × l0/l2 × 32/128ch × 3 seed × 多数据量）回答——发现了一系列**定量定律**（不是定性结论）：

### 发现的定量定律（14 条）
1. **数据替代幂律**：等变 gap ~ N^-1.49（容量充足），恒定 65（容量稀缺）
2. **数据效率律**：等变 = 4-6× 数据（容量稀缺）
3. **容量替代律**：4× 容量替代 61-91% 等变需求
4. **力径向主导律**：力误差 59-99% 径向
5. **阳离子调制律**：力 gap EMIM +1709 > BMIM +333 > Pyr14 -90（力 gap 阳离子驱动、阴离子无关）
6. **PAC 校准**：实证替代速率 3-4× 快于上界
7. **能量泛化理论**：精度 = f(力监督, 覆盖率, 测试跨度)
8. **化学精度交叉点**：N>9 时等变优势低于化学精度
9. **体相路径**：59 帧体相——力 RMSE 467→79（数据驱动提升）
10. **采样覆盖理论**：Pareto 权衡（近平衡 vs 高能量）
11-14. 其他（seed 鲁棒、维度特异、相对精度、外推量化）

## 四、集大成：统一标度律（我的定律）

所有定律 collapse 成**一个表达式**——**等变替代统一标度律**：

```
L = L∞ + A_s·N^(-α(s)) + B_s·D^(-β_eff(C; s, κ))
```

**核心洞察（对称性折扣）**：对称性 s 把问题复杂度 κ 降到有效复杂度 κ/s^m：
- 容量 C < κ/s^m → 数据替代不了等变（相变）
- 容量 C > κ/s^m → 数据替代 + 等变 exponent 更高 → 越大越强

**实证验证（Pyr14-FSI，每原子）**：
- β_eff：32ch 0.02 → 64ch 1.19 → 128ch 1.31
- **临界容量 C* ≈ 52.6 通道**（β_max=1.313，σ_w≈9% of C\*）——陡峭相变
- 三大极限退化 ✓ + 跨体系趋势 ✓ + 可复现推导 ✓

**为什么重要**：这是**第一个把"等变-数据-容量-复杂度"统一成一个可预测定律**的工作。给定体系复杂度 κ 和对称性 s，可以**直接预测**临界容量 C\*、数据效率、任意 (N, C) 的性能 gap——**无需训练**。它把"等变值多少钱"从经验问题变成**可计算、可预测的定律**，并且与 ICLR 2026 的最新 scaling-law 研究（Ngo & Ravanbakhsh）无缝合并（大尺度 scaling + 小尺度相变——单一光谱）。

**跨体系验证（进行中）**：用 Pyr14-NTf2（不同阴离子）测 β_eff/C\*——若 C\* 随阴离子变化 → 证明 κ（复杂度）的确由化学组成决定——**定律普适到不同 IL**。

## 五、这个定律意味着什么（对外表达）

**一句话**：等变性的价值不是固定的——它是由"数据、容量、复杂度"三方博弈决定的，而且这个博弈**服从一个可预测的相变定律**。

**给材料/化学界**：当你想用 MLIP 建模 IL 时，我的定律告诉你**该用多少容量、多少数据、选什么架构**——不用再靠试错。

**给 ML 界**：等变的优势不是恒定的（bitter lesson 的反面）——它在容量不足时最值钱（4-6× 数据），容量够了就衰减，而且**有一个临界容量 C\***——之后数据就能替代等变。

**给科学史**：这可能是**第一个"对称性作为可替代资源"的定量定律**——把数学的对称性概念，变成化学/材料学里的可计算资源。
